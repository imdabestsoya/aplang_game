# The Weight — Town Judge

An 8-bit game about accusations, fear and public judgment. Explore the town, connect evidence and make two-choice rulings across eight days. All gameplay runs in the game viewport, with fullscreen, keyboard and touch controls.

Run `npm ci`, then `npm run dev`; production: `npm run play`. Use Node 22.23.3 or newer supported by package.json.

Read [active PRD](docs/PRD.md), [status](docs/STATUS.md), and [judge handoff](docs/handoffs/town-judge.md). Older travel and card plans are historical.
